### स्टेप-बाय-स्टेप सेटअप प्रक्रिया:

#### स्टेप 1: Google Apps Script में कोड जोड़ें
1. अपने ब्राउज़र में जाएं: **[https://script.google.com/](https://script.google.com/)** (थाने के आधिकारिक Gmail अकाउंट से लॉगिन करें)।
2. बाईं तरफ **"New project"** पर क्लिक करें।
3. ऊपर प्रोजेक्ट का नाम बदलकर रख दें: `PS Malihabad Duty Backend`
4. एडिटर में जो डिफ़ॉल्ट कोड लिखा हो, उसे हटा दें (Ctrl+A फिर Backspace)।
5. अपनी फ़ाइल `backend/Code.gs` का सारा कोड कॉपी करके यहाँ पेस्ट कर दें।
6. ऊपर **Save (💾 फ्लॉपी आइकन)** पर क्लिक करें।

#### स्टेप 2: Web App के रूप में डिप्लॉय करें
1. ऊपर दाईं ओर नीले बटन **"Deploy"** पर क्लिक करें और **"New deployment"** चुनें।
2. बायीं ओर गियर (⚙️) आइकन पर क्लिक करके **"Web app"** चुनें।
3. निम्नलिखित सेटिंग्स भरें:
   * **Description:** `PS Malihabad Duty Backend v1`
   * **Execute as:** `Me (your-email@gmail.com)`
   * **Who has access:** `Anyone` *(महत्वपूर्ण: इसे Anyone रखें ताकि आपका वेब ऐप API रिक्वेस्ट स्वीकार कर सके)*
4. नीचे **"Deploy"** बटन पर क्लिक करें।
5. गूगल आपसे परमिशन मांगेगा:
   * **Authorize access** पर क्लिक करें।
   * अपना Google अकाउंट चुनें।
   * अगर *"Google hasn't verified this app"* स्क्रीन आए, तो नीचे **"Advanced"** पर क्लिक करें और फिर **"Go to PS Malihabad Duty Backend (unsafe)"** पर क्लिक करें।
   * **"Allow"** पर क्लिक करें।
6. अब आपको एक **Web app URL** मिलेगा जो इस प्रकार होगा:
   ```text
   https://script.google.com/macros/s/AKfycbx.../exec
   ```
7. इस URL को कॉपी कर लें।

#### स्टेप 3: फ्रंटएंड `js/config.js` में URL पेस्ट करें
अपने प्रोजेक्ट में फ़ाइल [js/config.js](file:///c:/Users/dkp/Downloads/duty-main/js/config.js) खोलें और `API_URL` में अपना कॉपी किया गया लिंक पेस्ट कर दें:

```javascript
window.APP_CONFIG = {
  // आपका Apps Script Web App URL:
  API_URL: "https://script.google.com/macros/s/YOUR_COPIED_ID/exec",

  // अगर Google Sign-In बटन नहीं लगाना और केवल Username/Password इस्तेमाल करना है,
  // तो GOOGLE_CLIENT_ID को ऐसे ही रहने दें या खाली छोड़ दें:
  GOOGLE_CLIENT_ID: "",

  CAPTURE_PUBLIC_IP: true,
  POLL_SECONDS: 30
};
```

  * `malihabad_db.json` (मुख्य डेटाबेस)

  * ऑटोमैटिक बैकअप फ़ाइलें
